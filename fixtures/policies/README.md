# Synthetic policy inputs

These are unevaluated, unsigned input templates, not an authority bootstrap.
The baseline uses illustrative repeated-digit dependency hashes; those are not
receipts for the adapter, prices, bounds or evaluation specification. Replace
them with the actual canonical frozen artifact digests before an operator can
evaluate and approve the bundle. Its future expiry is an input value, not a
freshness or live-provider guarantee. The evaluation specification is a template,
not an EvaluationRecord or a claimed successful run.

A future mock demo must construct real local synthetic artifacts, hash them using
shared canonical helpers, freeze the proposed baseline, sign a finite simulation
evaluation authorization, run the authorized evaluation, freeze its actual record,
inspect/sign the exact eligible approval, and activate generation0 by CAS.
No fixture may skip those steps, seed an active pointer, contain a private key,
or authorize real provider calls. Source-only construction has executed none.
